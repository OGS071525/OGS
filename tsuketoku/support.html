よくあるご質問（FAQ）

つけトクの利用に料金はかかりますか？

無料でご利用いただけます。アプリ内課金や広告表示はありません。

どうやって始めればよいですか？

App Storeからインストールし、Apple ID でサインインして表示名を決めるだけで始められます。あとは記録画面で立替を書き込むだけです。一緒に使う人は、記録画面の「人を増やす」からQRコードで友達リストに追加してください。

Apple ID でのサインインは必須ですか？

はい。あなたの記録をあなたのものとして管理するため、Apple ID でのサインインをお願いしています。サインインしていただくことで、機種変更やアプリを入れ直したあとでも、同じ人として元の記録に戻れます。メールアドレスは受け取りません。

「ノート」とは何ですか？

精算をおえるまでの記録のまとまりです。記録は1冊のノートにたまり、精算をおえるとそのノートは閉じて新しい1冊が始まります。ノートタブでは、表紙の色で「編集中／精算まち／精算ずみ」を見分けられます。

アプリを使っていない人も参加できますか？

はい。友達リストには、名前だけで追加することもできます。アプリを使っている人は「QRで友達を追加」から追加してください。

対応している端末を教えてください。

iOS 17.0 以降のiPhoneとiPadに対応しています。

支払う人を決めるゲームはどんなものがありますか？

ルーレット・じゃんけん対戦・あみだくじ・10秒ぴったりの4種類です。参加者は友達リストから選べます（記録中のノートの参加者とは別に選べます）。ゲームはすべて端末内で動作し、結果がサーバーに送信されることはありません。

精算の結果をみんなに知らせるには？

精算画面から「LINEでこの精算を送る」を押すと、「誰が誰にいくら」の文面をそのままLINEのトークへ送れます。LINEアカウントの連携やログインは不要です。

アプリ内でお金のやり取りはできますか？

できません。つけトクは金額を記録・集計して精算額を見やすくするアプリで、送金や決済の機能はありません。クレジットカード情報などの決済情報も取得していません。

記録したデータを削除できますか？

はい、立替の記録はアプリ内からいつでも編集・削除できます。アカウントに紐づくすべてのデータの削除をご希望の場合は、お問い合わせ窓口までご連絡ください。

同じノートのメンバーには何が見えますか？

あなたの表示名とアイコン、記録した立替の金額・メモ・日時、添付したレシート写真、立て替えた人・あとで払う人、精算の受け取り状況、編集履歴が表示されます。ノートの記録を見られるのは、そのノートに参加しているメンバーだけです。他のメンバーに知られたくない内容をメモに記録しないようご注意ください。

個人情報はどのように管理されていますか？

氏名・メールアドレス・電話番号・決済情報は取得していません。取得した情報はMicrosoft Azure上に暗号化して保管し、通信もHTTPSで保護しています。詳しくはプライバシーポリシーをご確認ください。

サインアウトすると記録は消えますか？

消えません。同じApple IDでサインインし直せば、元の記録に戻れます。

退会（アカウント削除）はできますか？

はい、アカウントの削除をご希望の場合は、お問い合わせ窓口（info@ogs.jp）までご連絡ください。本人確認の上、アカウントおよび関連データをすべて削除いたします。なお、ノートは複数人で共有するため、他のメンバーが記録した内容や精算の履歴は、そのメンバーの記録として残る場合があります。

  • エラーメッセージ（表示されている場合）
