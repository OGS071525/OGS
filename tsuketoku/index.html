つけトクとは？

飲み会・旅行・ランチ。誰かが立て替えた「あとで払うね」を、そのままにしていませんか。
つけトクは、メモ帳に書く感覚で立替を記録して、精算まで自動で計算してくれるiOSアプリです。 金額とメモを入れるだけで、「誰が誰にいくら払えばいいか」をアプリが教えてくれます。

記録は「ノート」1冊ずつにたまり、精算をおえるとその1冊が閉じて新しいノートが始まります。 イベントごとに1冊、という感覚でお使いいただけます。

「誰が払う？」で迷ったときは、ルーレット・じゃんけん・あみだくじ・10秒ぴったりのゲームで支払う人を決められます。 気まずくなりがちな精算の場面が、その場のちょっとした盛り上がりに変わります。

主な機能

📝

メモ帳みたいに記録

リングノートそのままの画面に「○○代 ○○円」と書くだけ。「飲み会」「ごはん」「カフェ」「タクシー」などのプリセットは、長押しで自由に編集・並べ替えできます。

💴

立替（たてかえ）の記録

立て替えた人と、あとで払う人をえらぶだけ。1人あたりの金額はその場で自動計算され、人数が変わってもすぐ再計算されます。

📓

ノート単位の管理

記録は1冊のノートにたまり、精算をおえると新しい1冊が始まります。表紙の色で「編集中／精算まち／精算ずみ」がひと目でわかります。

🧮

精算は自動計算

全員の貸し借りを合算して、送金の回数がいちばん少なくなる組み合わせを提示。受け取りは1件ずつチェックでき、その状態はメンバー全員に共有されます。

💬

LINEで精算を送る

「誰が誰にいくら」の文面を、そのままLINEのトークへ送れます。請求の連絡も、アプリの中で作ってそのまま共有できます。

👥

友達リスト

QRコードを読み取って友達を追加し、ノートの参加者はそこから選びます。アプリを使っていない人も、名前だけで追加できます。

📖

ページをめくって見返す

左右スワイプでノートのページをめくるように、過去の記録を見返せます。あとから編集もでき、誰がいつ変更したかの編集履歴も残ります。

🎤

音声入力・電卓・レシート

マイクに話すだけでメモと金額を入力。電卓で端数もその場で計算でき、撮ったレシートはメンバー全員で共有されます。

🎯

ルーレット

参加メンバーを並べて回すだけ。支払う人をその場でランダムに決められます。

✊

じゃんけん対戦

グー・チョキ・パーの勝ち抜きで支払う人を決定。勝った人が支払う「男気モード」もあります。

🪜

あみだくじ

定番のあみだくじで、線をたどるアニメーションつき。結果が出るまでのドキドキも楽しめます。

⏱️

10秒ぴったり

画面に数字を出さず、体内時計だけで10秒を当てるゲーム。いちばんズレた人が支払い（男気モードではぴったりだった人が支払い）。

利用シーン

  • 🍽️飲み会の幹事として、立て替えた分をまとめて精算したい
  • ✈️旅行や合宿の会計を、1冊のノートにまとめたい
  • 🤝友だち同士の立て替えが多く、貸し借りが分からなくなりがち
  • 🎲「今日は誰がおごる？」をゲームで決めたい
  • 🏠家族やパートナーと生活費を分けている

安心して使えます

  • Apple ID でサインインするため、機種変更やアプリの入れ直しのあとも同じ記録に戻れます
  • メールアドレスは受け取りません。表示名とアイコンはご自身で決められます
  • アプリ内で金銭のやり取りは行いません。決済情報も取得しません
  • ノートの記録を見られるのは、そのノートに参加しているメンバーだけです
  • アプリ内課金・広告はありません
