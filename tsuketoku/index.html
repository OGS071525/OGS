つけトクとは？

つけトクは、日々の支出をワンタップで記録し、グループでの割り勘をかんたんに管理できるiOSアプリです。
旅行・食事・日常の買い物など、あらゆるシーンでスマートにお金の管理ができます。

「誰が払う？」で迷ったときは、ルーレット・じゃんけん・あみだくじのミニゲームで支払う人を決められます。 気まずくなりがちな精算の場面が、その場のちょっとした盛り上がりに変わります。

LINEアカウントと連携すれば、LINEの友だちをグループに招待して記録を共有できます。連携せずにゲストとして使い始めることもできます。

主な機能

💴

ワンタップ記録

電卓UIで金額を入力し、ワンタップで支出を記録。メモも添えられます。

⚡

メモのクイック入力

「🍻 飲み会」「🍽️ ごはん」「☕ カフェ」「🚕 タクシー」など、よく使うメモを選ぶだけで入力できます。

👥

割り勘管理

グループ内のメンバーを選んで割り勘を設定。誰がいくら負担するか、一目でわかります。

🧮

合計サマリー

グループの合計金額をまとめて表示。今どれだけ使っているかがすぐに確認できます。

📂

グループ管理

旅行メンバー、同僚、家族など、シーンに合わせて複数グループを作成・切替できます。

📋

履歴・編集

過去の記録を一覧表示。編集・削除もかんたんに行えます。

🎯

ルーレット

参加メンバーを並べて回すだけ。支払う人をその場でランダムに決められます。

✊

じゃんけん対戦

グー・チョキ・パーの勝ち抜きで支払う人を決定。ゲスト参加者を加えることもできます。

🪜

あみだくじ

定番のあみだくじで、線をたどるアニメーションつき。結果が出るまでのドキドキも楽しめます。

🔗

LINE友だち招待

LINEアカウントを連携すると、ワンタップで友だちをグループに招待できます。

技術構成

つけトクは以下の技術を使用して開発・運用されています。

  • フロントエンド：Next.js / React によるアプリ画面
  • バックエンド：Microsoft Azure上で稼働するサーバーレスAPI（Azure Functions）
  • データベース：Azure Cosmos DBによるデータ管理
  • 認証：LINE Loginによるユーザー認証（連携しない場合はゲストとして利用）
  • ミニゲーム：すべて端末内で動作し、サーバーとの通信はありません
  • 通信：全通信をHTTPS（TLS）で暗号化
